# Hard/Wired Coast — field build 0.8 review, 2026-09-10

**Known facts.** No human playtest notes were available, and the workspace browser runner
could not launch. This review therefore uses the game's actual control logic, pacing values,
and dialogue triggers as read from `index.html`.

## Next-build decision

Keep both touch profiles, with TRACE/LOCK as the default and DUAL VECTOR as the advanced option.

| Priority | Change | Reason |
|---|---|---|
| Must | Remove TRACE's "left 43% means steering" rule | It prevents direct shots at enemies on the left. Touching the air car should steer; touching elsewhere should aim and fire. |
| Must | Add an aim reticle and lock confirmation | TRACE currently gives little feedback about shot direction. |
| Must | Add a dead zone and normalized movement to DUAL VECTOR | A center press can create stationary shots, while diagonal movement is faster than straight movement. |
| Must | Reduce the Overlord encounter from 198 required hits to about 90–100 | At realistic touch accuracy, the boss can last longer than both shore stages combined. |
| Must | Replace timed banter with event-driven banter | Ten-second remarks feel detached from play; low-hull remarks can also overwrite one another. |
| Should | Add a one-second stage-clear beat | The game currently deletes threats and changes stages at once, which weakens progression. |
| Should | Keep controls clear of the air car in portrait mode | The dual pads overlap the player's main action area. |
| Should | Preserve the final Overlord remark | The results overlay appears after 1.1 seconds and hides most of the four-second defeat line. |
| Later | Add optional short haptics | Fire, damage, relay destruction, and shield failure would benefit from touch feedback. |

Where the numbers come from: the Overlord core is 150 hp behind two 24 hp shield nodes
(`makeBoss`), so 198 hits; banter fires on `phaseTime % 10 === 0` after eight seconds; the
results overlay is a `setTimeout(..., 1100)` after the 4-second defeat line.

## Recommended pacing

- Black Tide: 15–20 seconds.
- Hard Land: 15–20 seconds.
- Overlord: 20–30 seconds.
- Full successful sortie: about one minute.

## Overlord dialogue moments

The next build triggers one concise line at each of these moments and nowhere else:

- Encounter begins.
- First shield node breaks.
- Shield fails.
- Player hull first drops below 40%.
- Core reaches 50%.
- Victory or defeat.

The dialogue system should pass a small event record such as
`{event, hullBand, accuracyBand, retries, controlMode}` to the local writer. That gives a clean
seam for a later live-generation connection while retaining authored offline fallbacks and
avoiding dialogue spam.

## Highest-value next increment

Repair TRACE controls, shorten the boss, and rebuild banter around game events before adding
content or live generation.
